# ♟️ C++ Chess Game

A console-based Chess game developed in C++ with complete game logic and two-player functionality.

## 📌 Features

- ✅ Standard 8x8 chessboard
- ✅ Object-Oriented Design
- ✅ Full rules implementation:
  - Check & Checkmate
  - Castling
  - En Passant
  - Pawn Promotion
- ✅ Turn-based gameplay (Player vs Player)
- ✅ Input validation and error handling
- ✅ Clean ASCII/console-based interface

## 🛠️ Built With

- **C++** (Standard C++17 or later)
- **Standard Template Library (STL)**
- **Console I/O**

## 🧠 Game Structure

- `main.cpp` – Entry point of the game
- `Board.cpp / Board.h` – Manages the chessboard and game state
- `Piece.cpp / Piece.h` – Base and derived classes for all chess pieces
- `Player.cpp / Player.h` – Handles player turns and input


## ▶️ How to Run

### 🔧 Step 1: Clone the Repository

git clone https://github.com/YourUsername/chess-game-cpp.git
cd chess-game-cpp
**
⚙️ Step 2: Compile the Code**
Using g++:


g++ -std=c++17 -o chess main.cpp
If you have multiple files:

g++ -std=c++17 -o chess main.cpp Board.cpp Piece.cpp Player.cpp
